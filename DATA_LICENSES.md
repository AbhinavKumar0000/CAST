## Attribution Requirements

When redistributing this repository or derived works:

1. **Code**: Include MIT license (LICENSE)
2. **UPAG data**: "Source: DES/MoA&FW via India Data Portal (UPAG), licensed under ODC-By"
3. **GADM**: "Administrative boundaries from GADM (gadm.org), licensed under CC-BY-4.0"
4. **Open-Meteo**: "Weather data from Open-Meteo (open-meteo.com), licensed under CC-BY-4.0"
5. **Ground truth tables**: "Compiled from public government sources (ICAR-CRIDA, SLBC-MP, evikas MP, TNAU, DPD)"

## Files NOT in Repository (Gitignored)

- `eval/runs/` — Raw run logs, model outputs, caches (contains API keys)
- `eval/cache/llm/` — LLM call caches
- `eval/cache/weather/` — Weather cache (can be regenerated)
- `.env` — Environment variables with API keys
- `__pycache__/`, `*.pyc` — Python bytecode
- `*.log`, `*.pid` — Runtime artifacts

These can be regenerated by running the pipeline (requires API keys for LLM steps).
