# n=500 headline figures + district-clustered contrasts

Canonical figure set for the final pre-registered evaluation (Nemotron-3-Ultra, n=500
scenarios / 51 districts). Generated by `eval/scripts/n500_figures.py`, which reads only the
frozen artifacts `eval/results/n500_primary_metrics.json` and
`eval/results/n500_clustered_inference.json` (+ `.txt` for the C2a-vs-C3 block). Outputs:
`eval/figures/n500/` (PDF + PNG @ 300 dpi) and per-figure data in `eval/figures/n500/data/`.

The headline cells are the **pilot-included** strict per-protocol table (`cells_WITH pilot_dev`,
all 500 scenarios). Contrasts are the four pre-registered pairs
(C2a−C0b, C2a−C1a, C2b−C0b, C2b−C1a) with a **district-clustered** bootstrap (resample 51
districts, not scenarios) and Holm correction over the four pairs.

| figure | content |
|---|---|
| `Fig_N01_condition_quality` | strict PP season-validity and hard-violation by condition (C0, C0b, C1a, C2a, C2b, C3) with 95% CIs |
| `Fig_N02_preregistered_forest` | four pre-registered contrasts, cluster CI (bold) vs scenario-level naive (grey), Holm p |
| `Fig_N03_design_effect` | district ICC by condition (sv/hv) and effective sample size vs nominal n |
| `Fig_N04_district_variation` | district-level C2b−C0b effect, 51 districts sorted, coloured by batch half |
| `Fig_N05_season_contrasts` | four contrasts within Kharif / Rabi / Zaid (cluster CI) |
| `Fig_N06_half_contrasts` | B1 vs B2 vs merged for C2b−C0b and C2b−C1a |
| `Fig_N07_c2a_vs_c3` | per-scenario C2a-vs-C3 match / beat / lose |

## Key numbers

Condition means (strict PP, n=500):

| cond | season validity | hard violation |
|---|---|---|
| C0 | 0.551 | 0.382 |
| C0b | 0.646 | 0.292 |
| C1a | 0.665 | 0.292 |
| C2a | 0.803 | 0.161 |
| C2b | 0.772 | 0.151 |
| C3 | 0.863 | 0.104 |

Pre-registered contrasts (strict PP sv; cluster CI; Holm over 4 pairs = 4.00e-04):

| pair | diff | cluster 95% CI | naive Holm |
|---|---|---|---|
| C2a−C0b | +0.161 | [+0.107, +0.214] | 2.7e-13 |
| C2a−C1a | +0.135 | [+0.094, +0.176] | 3.9e-15 |
| C2b−C0b | +0.128 | [+0.093, +0.160] | 2.8e-12 |
| C2b−C1a | +0.105 | [+0.069, +0.140] | 2.5e-11 |

All four are claimable on sv and hv, strict and lenient, PP and ITT. District clustering widens
the CIs but changes no claimability decision (0 / 16 cells change).

Design effect: only the tool-using conditions cluster (their ranking comes from
district-determined `crop_score`). Season-validity ICC is 0.166 for C2a (DEFF 2.47, ESS 203) and
0.084 for C2b; hard-violation ICC is 0.241 for C2a (DEFF 3.12, ESS 160). The paired contrasts are
essentially unclustered (C2b−C0b sv ICC 0.000, ESS 437).

District variation: the C2b−C0b effect has mean +0.123, between-district SD 0.134, range
−0.171 (Burhanpur) to +0.400 (Barwani); the B1/B2 gap is +0.094 = 0.70 SD — district-level
variation, not a clean batch effect.

Per-season (strict PP sv): Kharif C2a−C0b +0.275 / C2a−C1a +0.250 / C2b−C0b +0.168 /
C2b−C1a +0.142; Rabi +0.119 / −0.012 / +0.061 / −0.067; Zaid +0.053 / +0.167 / +0.163 / +0.276.

C2a vs C3 (n=500): sv strict match 0.722 / beat 0.026 / lose 0.252; hv strict 0.794 / 0.004 /
0.202; hv lenient 0.812 / 0.002 / 0.186.

## Superseded figures

The cross-model `Fig_M01–M10` and paper `Fig01–Fig14` sets use the older C1/C2 condition naming
and the partial cross-model run (llama 150, glm 32) and are **superseded as headline** by this
n=500 pre-registered set. The `Fig_E01–E06` set carries legacy hardcoded values (`n=8,628`) and
is superseded. All three sets were **moved** (not deleted) to
`eval/figures/archive_v1/{E_series,cross_model_M,paper}/`; see `eval/figures/SUPERSEDED.md`.
